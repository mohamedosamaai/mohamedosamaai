# Security Policy & Vulnerability Disclosure

## Supported Versions

Security updates are actively applied to the primary branch (`main`) of all production microservices and master repositories.

| Version / Branch | Supported |
| :--- | :---: |
| `main` | ✅ Active Security Support |
| Release Tags (`v1.x`) | ✅ Maintained |

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue or potential vulnerability across any Bagback Digital Solutions platform, please do NOT file a public GitHub issue.

Instead, please report security vulnerabilities directly to Mohamed Osama via email:
- **Email**: `hello@bagbacktech.com` / `im@mohamedosama.me`
- **Response SLA**: Within 24-48 hours

Please include:
1. Description of the vulnerability and potential impact.
2. Steps to reproduce or proof-of-concept payload.
3. Affected service or endpoint URL.

We appreciate responsible security disclosure and will coordinate remediation promptly.
